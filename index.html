Add a new account

For security, authentication accounts must first be created in Supabase Authentication. Never create users with a service-role key in this browser.

  1. Open Supabase Dashboard → Authentication → Users.
  2. Create the staff member's account using their own school-approved email.
  3. Copy the new user's UUID.
  4. Use the reviewed provisioning SQL template included in this V4 package to create their authorized profile.
  5. Ask the user to sign in and verify the assigned role.

Supported roles: Administrator, Registrar, Enrollment Staff, Read-only.
